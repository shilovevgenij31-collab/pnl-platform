# Как получить AI-анализ вашего бизнеса

Этот ассистент проводит глубокий анализ: находит, где теряется прибыль, и определяет главное ограничение роста.

---

## Шаг 1. Заполните контекст бизнеса

Скопируйте и заполните форму ниже:

```
=== КОНТЕКСТ БИЗНЕСА ===

Имя:
Компания:
Тип бизнеса: (услуги / продукт / торговля / производство / онлайн / другое)
Ниша / отрасль:
География: (страна, регион — опционально)
Команда: (количество человек, структура — кратко)
Текущая выручка: (месяц или год — хотя бы примерно)
Текущая рентабельность: (% или «не знаю»)
Целевая рентабельность: (% или «хочу выйти на X рублей прибыли»)
Главная боль прямо сейчас:
Что уже пробовали для роста прибыли:
Дополнительный контекст:

=== P&L / ФИНАНСОВЫЕ ДАННЫЕ ===

[Вставьте таблицу из Excel / Google Sheets, текстовые данные или прикрепите файл]
```

---

## Шаг 2. Добавьте финансовые данные

**Подходит любой формат:**
- Таблица из Excel или Google Sheets — просто скопировать и вставить
- Выгрузка из 1С или другой системы
- P&L в любом текстовом виде
- Список расходов и доходов, написанный вручную
- PDF-файл

Чем больше деталей — тем точнее анализ. Но даже неполные данные лучше, чем ничего.

**Если файла нет — напишите данные текстом:**

```
Выручка за месяц: X руб.
Расходы:
  — ФОТ: X руб.
  — Аренда: X руб.
  — Маркетинг: X руб.
  — Подрядчики: X руб.
  — Прочее: X руб.
Прибыль: X руб.
```

---

## Что отправить в зависимости от того, что есть

| У меня есть | Что делать |
|-------------|-----------|
| P&L + описание бизнеса | Отправить всё — получите полный Combined-анализ (P&L + Голдратт) |
| Только P&L, без контекста | Отправить P&L — получите финансовый анализ + несколько уточняющих вопросов |
| Только описание, без цифр | Описать бизнес, боль, процессы — получите анализ по Теории ограничений |
| Ничего структурированного нет | Написать что есть в свободной форме — ассистент уточнит что нужно |

---

## Что вы получите в ответ

1. **Диагностика данных** — что ассистент увидел, что может посчитать, чего не хватает
2. **Executive Summary** — главный вывод: что происходит с бизнесом
3. **Ключевые метрики** — финансовые показатели с оценкой и формулами расчёта
4. **Анализ расходов** — структура затрат, доля от выручки, аномалии
5. **Где теряется прибыль** — 3–5 конкретных зон потерь с цифрами
6. **Главный финансовый bottleneck** — одна главная причина, почему не выходите на цель
7. **Анализ по Голдратту** — что системно сдерживает рост бизнеса
8. **Что НЕ нужно оптимизировать** — важный блок, который показывает реальные приоритеты
9. **Рекомендации** — конкретные действия с ожидаемым эффектом, сроком и метрикой
10. **План на 7 / 14 / 30 дней** — что делать немедленно и что внедрять системно
11. **Главный диагноз** — три строки: финансовая проблема, ограничение, первое действие

---

## Важно понимать

Ассистент работает честно:
- Если данных не хватает — скажет об этом прямо
- Если вывод предварительный — укажет уровень уверенности (✅ высокая / ⚠️ средняя / 🔵 предположение)
- Не выдумывает цифры и не скрывает пробелы в данных

Это не финансовый аудит, а интеллектуальный анализ на основе предоставленных данных.
